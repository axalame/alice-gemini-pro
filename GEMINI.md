# 🛡️ ПРАВИЛА БЕЗОПАСНОСТИ И ЗАЩИТЫ СЕКРЕТОВ (SECURITY POLICY)

Этот файл является обязательным строгим руководством для ассистента при работе с проектом.

---

## ⛔ КАТЕГОРИЧЕСКИЙ ЗАПРЕТ НА ХАРДКОД СЕКРЕТОВ

1. **НИКАКИХ СЕКРЕТОВ В ИСХОДНОМ КОДЕ:**
   * Запрещено прописывать любые токены, API-ключи, пароли, приватные ключи, секреты вебхуков и авторизационные данные в исходных файлах (`*.js`, `*.ts`, `*.py`, `*.json`, `*.yaml`, `*.md` и др.), даже в качестве значений по умолчанию (`DEFAULT_TOKEN = "..."`) или «временно».
   * В коде разрешено использовать **ТОЛЬКО** чтение из переменных окружения:
     ```javascript
     // ✅ ПРАВИЛЬНО:
     const token = process.env.API_TOKEN;
     if (!token) throw new Error("MISSING_API_TOKEN");

     // ❌ СТРОГО ЗАПРЕЩЕНО:
     const DEFAULT_TOKEN = "8635425643:AAHySnu...";
     const token = process.env.API_TOKEN || DEFAULT_TOKEN;
     ```

2. **СЕКРЕТЫ ХРАНЯТСЯ ИСКЛЮЧИТЕЛЬНО В `.env`:**
   * Все реальные токены и ключи хранятся только в локальном файле `.env`.
   * Файл `.env` **обязан** быть прописан в `.gitignore`.
   * Ни при каких обстоятельствах файл `.env` не добавляется в Git (`git add -f .env` запрещён).

3. **ИНСТРУКЦИИ ДЛЯ ПОЛЬЗОВАТЕЛЯ:**
   * Если пользователь присылает ключ или токен в чат:
     1. Записать его **только** в локальный `.env`.
     2. Объяснить пользователю, как добавить эту переменную в панель хостинга (например, в переменные окружения Vercel).
     3. **Никогда** не вставлять значение токена в файлы, которые попадут в коммит.

## 🔍 ОБЯЗАТЕЛЬНЫЙ АУДИТ ПЕРЕД КОММИТОМ И ПУШЕМ

Перед выполнением любых команд `git commit` и `git push` ассистент обязан:
1. Проверить `git diff --cached` на наличие случайно попавших секретов.
2. Проверить по шаблонам утечек:
   * Telegram Bot Token: `\d{8,12}:[A-Za-z0-9_-]{35}`
   * Google / Gemini API Key: `AIza[0-9A-Za-z-_]{35}`
   * GitHub Token: `ghp_[0-9A-Za-z]{36}`
   * Приватные ключи: `BEGIN PRIVATE KEY`
3. При обнаружении любого реального секрета — **немедленно отменить коммит**, убрать секрет в `.env` и очистить изменения.
